# 02 · 邊緣感知與空間運算層 (Overview + TODO)

## Overview
職責：多模態採集 (眼動座標、凝視停留、頭部向量、聲學特徵)、SLAM 平面錨定、AR 渲染 (提示物件 / 代幣板 / 視覺排程 / 過渡倒數)、以及最關鍵的「確定性 ABA 規則引擎」。

規則引擎 = 一台有限狀態機：SD 發出 → 計時 → 反應分類 (幾何規則：視線向量與目標 bounding volume 夾角 < θ 且停留 ≥ 1s) → 後果派發 → 提示層級狀態轉移 (0-3 級，80% 準確率門檻觸發褪除)。所有參數由 BCBA 後台下發，本地唯讀。

本地隱私管線：人臉即時模糊 → 語音特徵雜湊 → 特徵抽取 → 原始幀丟棄 (僅留加密本地環形緩衝 24h 供事故調查)。
