# 05 · ABA 干預模組實作規則 (Overview + TODO)

## Overview
五個臨床模組的軟體化規格。全部即時邏輯在 L1，LLM 僅事後分析與調參建議。

1. JA 共同注意力：RJA 流程 = avatar 呼名 → 指向目標 → 3s 窗口 + 1s 停留判定 (本地幾何規則)。失敗 → 提示升級 (手指閃爍 → 物件放大 + 提示音)。IJA 為 Phase 2+。
2. DTT 離散嘗試：SD → 反應 → 後果閉環。無錯誤學習：新技能 0 秒延遲全提示；80% 獨立正確率觸發褪除 (發光箭頭 → 光暈 → 微放大 → 無提示)。錯誤修正：清空重置 → 原題重現 → 提示回升一級。
3. FCT 功能性溝通：休息卡 = BCBA 授權參數 (出現條件 / 次數上限 / 稀釋曲線)，系統不得自動調整 (見 08-C3)。
4. 動態偏好評估 MSWO：五物件不替換選擇，記錄順序權重 + 互動時長 + 迴避事件 → 偏好矩陣。飽足偵測 (延遲上升 / 錯誤率上升) → 輪換次高偏好物。
5. 視覺支持：常駐視覺排程 (完成打勾動畫)、工作分析逐步疊加 (洗手等 ADL)、過渡前 2 分鐘倒數計時器。

所有特效受感官設定檔過濾 (見 08-C2)。
