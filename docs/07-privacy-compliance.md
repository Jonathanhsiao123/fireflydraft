# 07 · 隱私與合規 (Overview + TODO)

## Overview
原則：原始影音不出裝置；雲端只收結構化去識別化特徵；三層同意 (家長 COPPA 同意 / 機構協議 / 個案 assent)。

法規對照 (美國部署)：HIPAA (若涉醫療服務提供者 → 需 BAA)、COPPA (13 歲以下可驗證家長同意)、FERPA (學區部署)、州級生物特徵法 (IL BIPA 等，眼動與聲紋屬之)。其他地區另行對照 (台灣個資法 / GDPR)。

資料保留：供應商端保留政策以官方合約條款為準 (勿依二手轉述，見 08-B1)；本地原始緩衝 24h 自動清除；衍生資料保留期限依 IRB / 機構政策。
