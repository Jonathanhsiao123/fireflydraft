# 03 · 智慧閘道與動態路由層 (Overview + TODO)

## Overview
供應商中立的推理介面。依任務複雜度路由至三個能力層級 (fast-tier / balanced-tier / deep-tier)，實際模型字串集中於 models.yaml，禁止硬編碼於業務邏輯。

路由矩陣 (草案)：
| 任務 | 層級 | 範例模型 (以官方文件為準) |
|---|---|---|
| 事件分類、簡單結構化抽取 | fast | Haiku 級 |
| 會話摘要、報告草稿 | balanced | Sonnet / Opus 級 |
| 週期性行為趨勢分析、IEP 目標建議草案 | deep | Fable 5 |

失敗處理：逾時 / 5xx / 限流 → 同級備援與重試 (exponential backoff)。安全拒絕 → 隔離佇列 + 雙人覆核，絕不自動改道 (見 08-A3)。

預算節流：每個案每月 token 配額、deep-tier 僅允許排程批次觸發、成本儀表板即時告警。
